## 1. 系统概述与核心电气规格

本驱动板专为五线舵机（2 线直流电机 + 3 线电位器位置反馈）设计，内置独立闭环控制 MCU，外部主控仅需通过 **I2C 总线**即可同时控制 10 路舵机的角度、速度或刹车状态，并实时读取各通道角度、ADC 原始值、输出占空比及堵转故障状态。

| 参数项 | 规格说明 | 备注 |
|---|---|---|
| **主控芯片** | `AI8051U-34K64`（LQFP48） | 40MHz 内部 HIRC，120MHz TFPU 浮点加速 + MDU32 硬件乘除 |
| **驱动芯片** | 5 颗双通道 `MX1616H` 全桥驱动 | 共 10 路独立 H 桥，支持正转、反转、滑行（Coast）、刹车（Brake） |
| **控制通道数** | 10 路（CH0 ~ CH9） | 对应接口 `JM0~JM9` 与 `JP0~JP9` |
| **PWM 规格** | 200Hz / 100 级分辨率（Timer0 20kHz） | 支持开环占空比 `-100% ~ +100%` |
| **闭环控制频率** | 1kHz（1ms 周期，Timer1 节拍） | 位置式 PID（`1.5°` 死区，积分限幅 `±400.0`） |
| **位置反馈采集** | 10 路 12 位循环 ADC（`0 ~ 4095`） | 4 阶指数滑动平均滤波（EMA），默认行程 `ADC 160~3935` 映射 `0.0° ~ 270.0°` |
| **堵转保护** | `|duty| >= 45%` 且 `400ms` 内 `|ΔADC| < 18` | 自动切断该通道 PWM 输出并置位 `FAULT[ch].bit0` |
| **I2C 从机参数** | 7 位地址 `0x40`（8 位写 `0x80` / 读 `0x81`） | 兼容 `100kHz` / `400kHz`，板载 `4.7kΩ` 上拉至 `3.3V` |
| **功率供电输入** | `J1`：DC **5V** | 建议 5V / 5A ~ 10A 开关电源（视并发舵机数量而定） |
| **电源总开关** | `SW3`（DPDT 拨动开关）+ `Q2`（`AO4407A` 15A P-MOS） | 双极联动同时通断 5V 功率电（`15A` 固态无弧开关）与 3.3V 逻辑电（含 USB 供电） |
| **逻辑供电** | 板载 `ME6211C33M5G-N`（3.3V LDO） | `J1` 与 Type-C `J2` 支持双模自动防倒灌切换 |
| **舵机端子额定电流** | `MX1.25` 端子（`1.25T-2A` / `1.25T-3A`） | 单端子额定 **3A** |

> [!WARNING]
> **Type-C（`J2`）仅用于逻辑供电与固件烧录，不能给 10 路舵机功率部分（`SERVO_5V`）供电！** 电机转动必须通过 `J1` 接入 5V 功率电源。

### 2.2 10 路五线舵机接口（`CH0 ~ CH9`）

## 3. 供电模式、接线注意事项与固件烧录指南

### 3.1 双模供电自动切换机制

板载 `Q1(AO3401A P-MOS)` + `D1/D2(B5819W)` + `R1(10kΩ)` 构成无跳线自动切换与防倒灌电路：

1. **模式 A：独立运行模式（仅接 `J1` 5V 功率电源）**
   - `VBUS_5V = 0V`（被 `R1` 拉低），`Q1` 导通，`SERVO_5V` 经 `Q1 -> D2 -> U7` 产生 `VCC_3V3`。
   - 仅需一路 5V 电源即可同时驱动电机与主控。
2. **模式 B：USB 调试 / 烧录模式（同时接 `J1` 与 `J2 Type-C`，或仅接 `J2`）**
   - 接入 `J2` 后 `VBUS_5V = 5V`，`Q1` 栅源反偏自动关断并依靠体二极管阻断反向通路，避免电机的电压倒灌进电脑 USB 口。
   - 此时电脑 Type-C 仅负责经 `D1 -> U7` 给逻辑部分供电，`J1` 专供舵机电机；若仅接 Type-C，可进行固件烧录与 I2C 寄存器读写调试，但舵机不会转动。

### 3.2 外部主控接线与电气注意事项

1. **I2C 三线共地连接**：外部主控连接 `J3` 时，通常只需连接 **`GND`（Pin 2）、`I2C_SCL`（Pin 3）、`I2C_SDA`（Pin 4）**。
2. **禁止电源冲突**：**切勿将 `J3 Pin 1 (VCC_3V3)` 直接短接到外部主控板自身的 3.3V 稳压输出端！** 仅当外部 I2C 电平转换器或低功耗传感器需要参考电源时才可从 `J3 Pin 1` 取电。
3. **5V 主控电平匹配**：本板 I2C 已上拉至 **3.3V**。若外部主控（如 5V 供电的单片机）工作在 5V IO 电平，强烈建议将外部主控切换至 3.3V 供电，或在 SCL/SDA 上增加双向 I2C 电平转换模块（如 BSS138），以免 5V 上拉向 `VCC_3V3` 倒灌。
4. **五线舵机电位器极性校验（上电必查）**：
   - 固件默认正占空比（`Mx_A` 为高、`Mx_B` 为低）应使电位器反馈电压 `POT_x` **升高**（ADC 读数增大）。
   - 如果下发位置指令后舵机朝相反方向狂转撞击限位并在 `400ms` 后红灯快闪（触发堵转），说明电机或电位器极性反了：**断电后对调该路 `JMx` 的两根电机线即可解决**（切勿带电热插拔功率端子）。

### 3.3 AIapp-ISP USB 固件烧录步骤

1. 确保电源总开关 **`SW3 (MAIN PWR)` 处于 `ON` 档**，用 Type-C 数据线连接 `J2` 与电脑（无需接 `J1` 5V）。
2. **按住 `SW2 (BOOT)` 不放** -> **短按一下 `SW1 (PWR)` 复位**（或按住 `SW2` 再插上 Type-C）-> **松开 `SW2`**。
3. 打开 **AIapp-ISP（STC-ISP）** 软件，识别到 `STC USB Writer (HID1)` 设备。
4. 芯片型号选择 **`AI8051U-34K64`**，调入项目编译生成的 `.hex` 文件，内部 IRC 时钟选 `40MHz`（注：固件启动后 `sys_clock_init()` 会自动重配 40MHz HIRC 与 120MHz PLL）。
5. 点击“下载/编程”即可完成烧录。

## 4. I2C 通信协议与完整寄存器映射表

### 4.1 协议基础与原子提交机制

- **7 位从机地址**：`0x40`（对应 8 位写地址 **`0x80`**，8 位读地址 **`0x81`**）。
- **支持速率**：标准模式 `100kHz`、快速模式 `400kHz`。
- **写操作时序**：`START -> 0x80 -> RegAddr -> Data0 [-> Data1 ...] -> STOP`
  - 每次写入后寄存器地址指针自动加 1（按 128 取模循环）。
  - **原子提交特性**：驱动板在 I2C 中断中将接收数据暂存于 `i2c_regs[]`，直到主机发送 **`STOP` 或 `Repeated START`** 时才统一置位 `i2c_dirty_mask` 通知主循环生效。因此，连续写入 2 字节 16 位目标值或一次性写入 10 路目标值（20 字节）不会出现高低字节撕裂。
- **读操作时序**：`START -> 0x80 -> RegAddr -> ReSTART -> 0x81 -> Read Byte0 (ACK) ... -> Read LastByte (NACK) -> STOP`
  - 从机在每次收到主机 `ACK` 后自动将寄存器地址指针加 1，方便主机连续读出全部遥测数据。

### 4.2 128 字节寄存器映射表（多字节均为 Little-Endian 小端序）

| 地址范围 | 寄存器名 | 权限 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|---|
| `0x00` | `G_CTRL` | R/W | `uint8_t` | `0x01` | 全局控制字：<br>• `bit0 (0x01)`：`en_all`（1=使能输出，0=全局急停）<br>• `bit1 (0x02)`：`save_eeprom`（写 1 保存 PID 与校准参数到 EEPROM 并自动清零；**写入时请保留 bit0**，如写 `0x03`，且保存约耗时 20ms，主机需延时 `>= 50ms` 再发下一帧）<br>• `bit2 (0x04)`：`clear_faults`（写 1 清除全部堵转故障并自动清零；**写入时请保留 bit0**，如写 `0x05`） |
| `0x01` | `G_STATUS` | RO | `uint8_t` | `0x01` | 全局状态字：<br>• `bit0 (0x01)`：当前 `en_all` 状态<br>• `bit1 (0x02)`：任意通道存在故障（`any_fault`） |
| `0x02..0x15` | `TARGET[0..9]` | R/W | `int16_t` LE | `1350` | 每路 2 字节，通道 `ch` 地址 = `0x02 + ch*2`：<br>• `POS` 模式：`0 ~ 2700`（代表 `0.0° ~ 270.0°`，`0.1°/LSB`）<br>• `SPEED` 模式：`-100 ~ +100`（代表 `%` PWM 占空比）<br>• 注：当目标值变化绝对值 `> 30` 时，自动清除该通道堵转故障 |
| `0x16..0x1F` | `MODE[0..9]` | R/W | `uint8_t` | `0` | 每路 1 字节，通道 `ch` 地址 = `0x16 + ch`：<br>• `0` = `COAST`（滑行断电）<br>• `1` = `POS`（闭环位置 PID）<br>• `2` = `SPEED`（开环速度 PWM）<br>• `3` = `BRAKE`（电磁刹车 `INA=INB=1`）<br>• 注：切换模式会自动清空该通道 PID 积分项与堵转故障 |
| `0x20..0x33` | `POS_NOW[0..9]` | RO | `int16_t` LE | — | 当前角度，通道 `ch` 地址 = `0x20 + ch*2`，范围 `0 ~ 2700`（`0.0° ~ 270.0°`） |
| `0x34..0x47` | `ADC_NOW[0..9]` | RO | `uint16_t` LE | — | 滤波后 12 位 ADC 值，通道 `ch` 地址 = `0x34 + ch*2`，范围 `0 ~ 4095` |
| `0x48..0x51` | `DUTY_NOW[0..9]` | RO | `int8_t` | `0` | 当前输出占空比，通道 `ch` 地址 = `0x48 + ch`，范围 `-100 ~ +100`（`127` 表示刹车） |
| `0x52..0x5B` | `FAULT[0..9]` | RO | `uint8_t` | `0` | 通道故障字，通道 `ch` 地址 = `0x52 + ch`：`bit0 = 1` 表示堵转故障 |
| `0x5C..0x5D` | `KP_X100` | R/W | `uint16_t` LE | `35` | 比例系数 `Kp × 100`（默认 `35` 即 `Kp = 0.35`） |
| `0x5E..0x5F` | `KI_X100` | R/W | `uint16_t` LE | `2` | 积分系数 `Ki × 100`（默认 `2` 即 `Ki = 0.02`） |
| `0x60..0x61` | `KD_X100` | R/W | `uint16_t` LE | `8` | 微分系数 `Kd × 100`（默认 `8` 即 `Kd = 0.08`） |

### 4.3 推荐控制流程

1. 上电等待 `50ms` 以上，读取 `G_STATUS (0x01)` 与 `POS_NOW[ch]`，确认 I2C 通信正常及各路当前初始角度。
2. **先写目标角度 `TARGET[ch]`，再将 `MODE[ch]` 设为 `1`（`POS`）**——可避免切换瞬间以默认 `135.0°` 猛冲。
3. 周期读取 `POS_NOW`、`FAULT` 或 `G_STATUS` 监控到位与堵转情况。
4. 若某通道发生堵转保护（`FAULT[ch] & 0x01`），排除机械卡阻后，向 `G_CTRL` 写入 `0x05`（`en_all | clear_faults`）或下发变化量 `> 30` 的新目标即可恢复。

## 5. 外部主控 C 语言驱动代码：STM32（HAL 库硬件 I2C）

适用于 STM32F1 / F4 / G4 / H7 等所有支持 **STM32 HAL 库**的型号（如 CubeMX 配置 I2C1 为 `100kHz` 或 `400kHz`，7 位地址模式）。注意 HAL 库的 `DevAddress` 参数需要传 **左移 1 位后的 8 位地址**（`0x40 << 1 = 0x80`）。

### 5.1 `servo_board_stm32.h`

```c
#ifndef __SERVO_BOARD_STM32_H__
#define __SERVO_BOARD_STM32_H__

#ifdef __cplusplus
extern "C" {
#endif

#include <stdint.h>
#include "main.h" /* 包含对应系列 HAL 头文件，例如 stm32f1xx_hal.h / stm32f4xx_hal.h */

#define SERVO_BOARD_I2C_ADDR_7BIT   0x40U
#define SERVO_BOARD_I2C_ADDR_8BIT   ((uint16_t)(SERVO_BOARD_I2C_ADDR_7BIT << 1))
#define SERVO_BOARD_CH_COUNT        10U

/* 寄存器地址定义 */
#define SB_REG_G_CTRL               0x00U
#define SB_REG_G_STATUS             0x01U
#define SB_REG_TARGET_BASE          0x02U
#define SB_REG_MODE_BASE            0x16U
#define SB_REG_POS_BASE             0x20U
```

```c
        tlm->fault[i]       = raw[50U + i];

    return HAL_OK;
```

## 6. 外部主控 C 语言驱动代码：AI8051U（Keil C251 硬件 I2C 主机）

适用于另一颗 **AI8051U** 作为外部主控（Keil C251 编译环境，建议 3.3V 供电）。

> [!IMPORTANT]
> **AI8051U 硬件 I2C 要点**：
> 1. 操作 `I2CCFG`、`I2CPSCR`、`I2CMSCR`、`I2CMSST`、`I2CTXD`、`I2CRXD` 等 XFR 寄存器前，必须确保 **`P_SW2 |= 0x80`（`EAXFR = 1`）**。
> 2. `P_SW2[5:4]`（`I2C_S[1:0]`）引脚切换：`00 = P2.4(SCL)/P2.3(SDA)`、`01 = P1.5(SCL)/P1.4(SDA)`、`11 = P3.2(SCL)/P3.3(SDA)`，对应引脚须设为**开漏 + 内部上拉**。
> 3. 波特率公式：`MSSPEED = (FOSC / (4 * I2C_FREQ)) - 2`，支持高位扩展寄存器 `I2CPSCR`，在 40MHz 主频下可精准跑 `100kHz` 或 `400kHz`。

### 6.2 `servo_board_ai8051u.c`

```c
#include "servo_board_ai8051u.h"

#define I2C_WAIT_TIMEOUT    50000UL

static void sb_delay_ms(u16 ms)
{
    u16 i, j;
    for (i = 0U; i < ms; i++) {
        for (j = 0U; j < 4000U; j++) { }
    }
}

/* 等待硬件 I2C 主机当前指令完成，返回 1 成功，0 超时 */
static u8 sb_i2c_wait(void)
{
    u32 cnt = I2C_WAIT_TIMEOUT;
    while ((I2CMSST & 0x40U) == 0U) {
        if (--cnt == 0UL) {
            return 0U;
        }
    }
    I2CMSST &= ~0x40U; /* 软件清零 MSIF */
    return 1U;
}

/* 发送命令并检查从机 ACK（MSACKI=0 表示 ACK，1 表示 NACK） */
static u8 sb_i2c_cmd_tx_check_ack(u8 cmd, u8 dat)
{
    I2CTXD = dat;
    I2CMSCR = cmd; /* 0x09: START+TX+RACK, 0x0A: TX+RACK */
    if (sb_i2c_wait() == 0U) {
        return 0U;
    }
    return ((I2CMSST & 0x02U) == 0U) ? 1U : 0U;
}

static void sb_i2c_stop(void)
{
    I2CMSCR = 0x06U; /* STOP */
    sb_i2c_wait();
}

u8 sb_i2c_init(u32 fosc_hz, u32 i2c_freq_hz, u8 pin_group)
{
    u32 msspeed;

    P_SW2 |= 0x80U; /* EAXFR = 1，使能访问 XFR */

    /* 根据所选引脚组配置为开漏 + 内部上拉 */
    if (pin_group == AI8051U_I2C_PIN_P15_P14) {
        P1M1 |= 0x30U; P1M0 |= 0x30U; P1PU |= 0x30U;
    } else if (pin_group == AI8051U_I2C_PIN_P32_P33) {
        P3M1 |= 0x0CU; P3M0 |= 0x0CU; P3PU |= 0x0CU;
    } else {
        pin_group = AI8051U_I2C_PIN_P24_P23;
        P2M1 |= 0x18U; P2M0 |= 0x18U; P2PU |= 0x18U;
    }
    P_SW2 = (u8)((P_SW2 & ~0x30U) | (pin_group & 0x30U));

    if (fosc_hz >= (8UL * i2c_freq_hz)) {
        msspeed = (fosc_hz - 8UL * i2c_freq_hz) / (4UL * i2c_freq_hz);
    } else {
        msspeed = 0UL;
    }

    I2CCFG  = (u8)(0xC0U | (msspeed & 0x3FU)); /* ENI2C=1, MSSL=1 */
    I2CPSCR = (u8)((msspeed >> 6) & 0xFFU);    /* 高位分频扩展 */
    I2CMSST = 0x00U;
    I2CMSCR = 0x00U; /* 查询模式，关闭主机中断 */
    return 1U;
}

u8 sb_write_reg(u8 reg_addr, const u8 *buf, u8 len)
{
    u8 i;
    P_SW2 |= 0x80U;

    if (sb_i2c_cmd_tx_check_ack(0x09U, SB_I2C_WRITE_ADDR) == 0U) { sb_i2c_stop(); return 0U; }
    if (sb_i2c_cmd_tx_check_ack(0x0AU, reg_addr) == 0U)          { sb_i2c_stop(); return 0U; }
    for (i = 0U; i < len; i++) {
        if (sb_i2c_cmd_tx_check_ack(0x0AU, buf[i]) == 0U)        { sb_i2c_stop(); return 0U; }
    }
    sb_i2c_stop();
    return 1U;
}

u8 sb_read_reg(u8 reg_addr, u8 *buf, u8 len)
{
    u8 i;
    if (len == 0U) { return 1U; }
    P_SW2 |= 0x80U;

    if (sb_i2c_cmd_tx_check_ack(0x09U, SB_I2C_WRITE_ADDR) == 0U) { sb_i2c_stop(); return 0U; }
    if (sb_i2c_cmd_tx_check_ack(0x0AU, reg_addr) == 0U)          { sb_i2c_stop(); return 0U; }
    if (sb_i2c_cmd_tx_check_ack(0x09U, SB_I2C_READ_ADDR) == 0U)  { sb_i2c_stop(); return 0U; }

    for (i = 0U; i < len; i++) {
        I2CMSCR = (i == (u8)(len - 1U)) ? 0x0CU : 0x0BU; /* 末字节 RX+TNAK，其余 RX+TACK */
        if (sb_i2c_wait() == 0U) {
            sb_i2c_stop();
            return 0U;
        }
        buf[i] = I2CRXD;
    }
    sb_i2c_stop();
    return 1U;
}

u8 sb_set_global_enable(u8 enable)
{
    u8 v = (enable != 0U) ? 0x01U : 0x00U;
    return sb_write_reg(SB_REG_G_CTRL, &v, 1U);
}

u8 sb_clear_faults(u8 keep_enable)
{
    u8 v = (keep_enable != 0U) ? 0x05U : 0x04U;
    return sb_write_reg(SB_REG_G_CTRL, &v, 1U);
}

u8 sb_save_eeprom(u8 keep_enable)
{
    u8 v = (keep_enable != 0U) ? 0x03U : 0x02U;
    u8 ok = sb_write_reg(SB_REG_G_CTRL, &v, 1U);
    if (ok != 0U) {
        sb_delay_ms(50U);
    }
    return ok;
}

u8 sb_set_mode(u8 ch, u8 mode)
{
    if (ch >= SB_CH_COUNT) { return 0U; }
    return sb_write_reg((u8)(SB_REG_MODE_BASE + ch), &mode, 1U);
}

u8 sb_set_target_pos(u8 ch, s16 deg_x10)
{
    u8 buf[2];
    if (ch >= SB_CH_COUNT) { return 0U; }
    if (deg_x10 < 0)    { deg_x10 = 0; }
    if (deg_x10 > 2700) { deg_x10 = 2700; }
    buf[0] = (u8)((u16)deg_x10 & 0xFFU);
    buf[1] = (u8)(((u16)deg_x10 >> 8) & 0xFFU);
```

## 7. 外部主控 C 语言驱动代码：STC32G（Keil C251 硬件 I2C 主机）

适用于 **STC32G12K128 / STC32G8K64** 系列作为外部主控（Keil C251 编译环境，建议 3.3V 供电）。

> [!IMPORTANT]
> **STC32G 与 AI8051U 的硬件关键差异（请勿直接混用）**：
> 1. **`P_SW2[5:4]` 引脚映射不同**：STC32G 对应关系为 `00 = P1.5(SCL)/P1.4(SDA)`、`01 = P2.5(SCL)/P2.4(SDA)`、`10 = P7.7(SCL)/P7.6(SDA)`、`11 = P3.2(SCL)/P3.3(SDA)`。
> 2. **无 `I2CPSCR` 高位分频寄存器**：STC32G 的 `I2CCFG[5:0]` 只有 6 位 `MSSPEED`（最大 `63`），公式 `MSSPEED = (FOSC / (4 * I2C_FREQ)) - 2` 须钳位在 `0 ~ 63`。例如：
>    - `24MHz` 主频下 `100kHz` -> `MSSPEED = 58`（合法）；`400kHz` -> `MSSPEED = 13`。
>    - `35MHz` 主频下 `100kHz` 算得 `85` 超出 `63`，此时建议配置为 **`200kHz`（`MSSPEED = 42`）** 或 **`400kHz`（`MSSPEED = 20`）**。

### 7.2 `servo_board_stc32g.c`

```c
#include "servo_board_stc32g.h"

#define STC32G_I2C_TIMEOUT  50000UL

static void stc_delay_ms(u16 ms)
{
    u16 i, j;
    for (i = 0U; i < ms; i++) {
        for (j = 0U; j < 3000U; j++) { }
    }
}

static u8 stc_i2c_wait(void)
{
    u32 cnt = STC32G_I2C_TIMEOUT;
    while ((I2CMSST & 0x40U) == 0U) {
        if (--cnt == 0UL) {
            return 0U;
        }
    }
    I2CMSST &= ~0x40U;
    return 1U;
}

static u8 stc_i2c_tx_ack(u8 cmd, u8 dat)
{
    I2CTXD = dat;
    I2CMSCR = cmd; /* 0x09: START+TX+RACK, 0x0A: TX+RACK */
    if (stc_i2c_wait() == 0U) {
        return 0U;
    }
    return ((I2CMSST & 0x02U) == 0U) ? 1U : 0U;
}

static void stc_i2c_stop(void)
{
    I2CMSCR = 0x06U;
    stc_i2c_wait();
}

u8 sb_stc32g_i2c_init(u32 fosc_hz, u32 i2c_freq_hz, u8 pin_group)
{
    u32 msspeed;

    P_SW2 |= 0x80U; /* EAXFR = 1 */

    if (pin_group == STC32G_I2C_PIN_P15_P14) {
        P1M1 |= 0x30U; P1M0 |= 0x30U; P1PU |= 0x30U;
    } else if (pin_group == STC32G_I2C_PIN_P25_P24) {
        P2M1 |= 0x30U; P2M0 |= 0x30U; P2PU |= 0x30U;
    } else if (pin_group == STC32G_I2C_PIN_P77_P76) {
        P7M1 |= 0xC0U; P7M0 |= 0xC0U; P7PU |= 0xC0U;
    } else {
        pin_group = STC32G_I2C_PIN_P32_P33;
        P3M1 |= 0x0CU; P3M0 |= 0x0CU; P3PU |= 0x0CU;
    }
    P_SW2 = (u8)((P_SW2 & ~0x30U) | (pin_group & 0x30U));

    if (fosc_hz >= (8UL * i2c_freq_hz)) {
        msspeed = (fosc_hz - 8UL * i2c_freq_hz) / (4UL * i2c_freq_hz);
    } else {
        msspeed = 0UL;
    }
    if (msspeed > 63UL) {
        msspeed = 63UL; /* STC32G MSSPEED 最大为 6 位 (63) */
    }

    I2CCFG  = (u8)(0xC0U | (u8)msspeed); /* ENI2C=1, MSSL=1 */
    I2CMSST = 0x00U;
    I2CMSCR = 0x00U;
    return 1U;
}

u8 sb_stc32g_write_reg(u8 reg_addr, const u8 *buf, u8 len)
{
    u8 i;
    P_SW2 |= 0x80U;

    if (stc_i2c_tx_ack(0x09U, SB_I2C_WRITE_ADDR) == 0U) { stc_i2c_stop(); return 0U; }
    if (stc_i2c_tx_ack(0x0AU, reg_addr) == 0U)          { stc_i2c_stop(); return 0U; }
    for (i = 0U; i < len; i++) {
        if (stc_i2c_tx_ack(0x0AU, buf[i]) == 0U)        { stc_i2c_stop(); return 0U; }
    }
    stc_i2c_stop();
    return 1U;
}

u8 sb_stc32g_read_reg(u8 reg_addr, u8 *buf, u8 len)
{
    u8 i;
    if (len == 0U) { return 1U; }
    P_SW2 |= 0x80U;

    if (stc_i2c_tx_ack(0x09U, SB_I2C_WRITE_ADDR) == 0U) { stc_i2c_stop(); return 0U; }
    if (stc_i2c_tx_ack(0x0AU, reg_addr) == 0U)          { stc_i2c_stop(); return 0U; }
    if (stc_i2c_tx_ack(0x09U, SB_I2C_READ_ADDR) == 0U)  { stc_i2c_stop(); return 0U; }

    for (i = 0U; i < len; i++) {
        I2CMSCR = (i == (u8)(len - 1U)) ? 0x0CU : 0x0BU;
        if (stc_i2c_wait() == 0U) {
            stc_i2c_stop();
            return 0U;
        }
        buf[i] = I2CRXD;
    }
    stc_i2c_stop();
    return 1U;
}

u8 sb_stc32g_set_global_enable(u8 enable)
{
    u8 v = (enable != 0U) ? 0x01U : 0x00U;
```

## 8. 常见问题排查（FAQ）

1. **舵机一通电就朝反方向狂转撞击限位，随后停转且红灯 5Hz 快闪？**
   - **原因**：电机转向与电位器电压变化方向相反，正反馈导致冲顶并触发 400ms 堵转保护。
   - **解决**：断电后对调该路 `JMx` 的两根电机线（`Mx_A` 与 `Mx_B`），重新上电即可。
2. **外部主控发送 I2C 后总是返回 NACK / 无响应？**
   - 检查从机地址：7 位地址为 `0x40`，8 位写/读地址分别为 `0x80` / `0x81`；
   - 检查 `J3` 接线：`GND` 是否共地、`SCL(Pin3)` / `SDA(Pin4)` 是否接反；
   - 若使用 AI8051U / STC32G 作主控，确认已置位 `P_SW2 |= 0x80` 且 `P_SW2[5:4]` 引脚组与实际连线一致；
   - 确认驱动板 `LED1`（绿色电源灯）常亮、`LED2`（红色状态灯）正在闪烁。
3. **发送清故障或保存 EEPROM 后，所有舵机突然停止输出？**
   - **原因**：向 `G_CTRL (0x00)` 写入 `0x04` 或 `0x02` 时把 `bit0 (en_all)` 覆盖成了 `0`。
   - **解决**：保持输出使能时应写 **`0x05`**（清故障）或 **`0x03`**（保存 EEPROM）。
4. **多路舵机同时大角度快速转动时，驱动板复位或 `LED1` 闪烁？**
   - **原因**：`J1` 外部 5V 电源输出电流不足或线径太细，瞬间大电流拉低 `SERVO_5V`。
   - **解决**：更换 `5V / 5A ~ 10A` 稳压电源并缩短 `J1` 供电线；调试阶段可同时接入 Type-C 进入模式 B 隔离逻辑供电。
5. **舵机到达目标附近轻微抖动或响应偏慢？**
   - 可通过写 `0x5C..0x61` 调整全局 PID 参数（先调 `Kp` 决定响应速度，再加 `Kd` 抑制超调与抖动，最后微调 `Ki` 消除静差；固件内置 `±1.5°` 死区防止微抖），调试满意后写 `G_CTRL = 0x03` 保存到 EEPROM。
